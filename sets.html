Sets

SS1 General Mathematics — First Term

What is a Set?

A set is a well-defined collection of objects or items.

The objects in a set are called elements or members of the set.

For example:

A = {1, 2, 3, 4, 5}

Ways of Representing Sets

1. Roster Method

The elements are listed inside curly brackets.

B = {a, e, i, o, u}

2. Set-Builder Method

A set can also be described using a rule that its elements satisfy.

Types of Sets

  • Empty Set: A set with no elements.
  • Finite Set: A set with a definite number of elements.
  • Infinite Set: A set that continues without end.
  • Singleton Set: A set containing only one element.

Quick Revision

  • A set is a well-defined collection of objects.
  • The objects in a set are called elements.
  • Curly brackets { } are used to represent sets.
  • A set can be represented using the roster method.
  • A set can also be represented using the set-builder method.
