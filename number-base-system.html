What is a Number Base?

A number base is a system used to represent numbers using a particular set of digits.

The most commonly used number system is the decimal system, which has base 10.

Common Number Bases

  • Base 2: Binary — uses 0 and 1.
  • Base 5: Uses digits 0 to 4.
  • Base 8: Octal — uses digits 0 to 7.
  • Base 10: Decimal — uses digits 0 to 9.
  • Base 16: Hexadecimal — uses 0 to 9 and A to F.

Example

The number 1011₂ is written in base 2.

To convert it to base 10:

1011₂ = (1 × 2³) + (0 × 2²) + (1 × 2¹) + (1 × 2⁰)

= 8 + 0 + 2 + 1

Therefore, 1011₂ = 11₁₀.

Quick Revision

  • A number base determines the digits that can be used.
  • Binary is base 2.
  • Octal is base 8.
  • Decimal is base 10.
  • Hexadecimal is base 16.
